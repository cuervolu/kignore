scenario case/sensitive-by-default
kind normative
spec Patterns are case sensitive unless Git is told otherwise.
file .gitignore
| Readme.md
| *.LOG
| [A-C]x
path Readme.md
path readme.md
path README.MD
path a.LOG
path a.log
path Ax
path ax

scenario case/ignorecase-enabled
kind platform
spec core.ignorecase makes Git match patterns without regard to case.
note The setting is chosen by the user or by the filesystem at clone time, so it is not part of the portable semantics.
config core.ignorecase=true
file .gitignore
| Readme.md
| *.LOG
| build/
path Readme.md
path readme.md
path README.MD
path a.log
path a.Log
path BUILD/
path Build/
path other/build/
