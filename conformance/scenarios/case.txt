file .gitignore
| Readme.md
| *.LOG
| [A-C]x
path Readme.md
path readme.md
path README.MD
path a.LOG
path a.log
path Ax
path ax

scenario case/ignorecase-enabled
kind platform
spec core.ignorecase makes Git match patterns without regard to case.
note The setting is chosen by the user or by the filesystem at clone time, so it is not part of the portable semantics.
config core.ignorecase=true
file .gitignore
| Readme.md
| *.LOG
| build/
path Readme.md
path readme.md
path README.MD
path a.log
path a.Log
path BUILD/
path Build/
path other/build/

scenario case/ignorecase-escaped-letters
kind platform
spec core.ignorecase folds the path, so an escaped upper case letter in a pattern never matches while an escaped lower case letter matches both cases.
note Found by the differential fuzzer. Git folds the pattern before it reads the escape, so the escaped letter is compared as written.
config core.ignorecase=true
file .gitignore
| A\B
| c\d
| E\f
path ab
path AB
path cd
path CD
path ef
path EF
