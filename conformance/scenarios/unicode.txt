scenario unicode/bmp-literal
kind normative
spec Patterns are compared byte for byte, so non-ASCII characters match themselves.
file .gitignore
| caf`u00E9
| `u65E5`u672C`u8A9E/
| `u00FC*
path caf`u00E9
path cafe
path dir/caf`u00E9
path `u65E5`u672C`u8A9E/
path `u65E5`u672C`u8A9E
path `u00FCber
path uber

scenario unicode/wildcards-match-whole-characters
kind git-quirk
spec A question mark matches any one character except a slash.
note Git compares bytes, so a question mark matches a single byte and not a whole non-ASCII character.
file .gitignore
| caf?
| a?b
| a??b
path caf`u00E9
path cafe
path a`u00E9b
path a`u00E9`u00E9b
path a`u4E16b
path a`u4E16`u4E16b

scenario unicode/bracket-with-non-ascii
kind git-quirk
spec A bracket expression matches one of the listed characters.
note Git compares bytes, so a non-ASCII member of a bracket expression is a set of bytes.
file .gitignore
| a[`u00E9`u00E8]
| b[^x]
path a`u00E9
path a`u00E8
path ae
path b`u00E9
path bx

scenario unicode/outside-bmp-question-mark
kind git-quirk

scenario unicode/precomposeunicode-enabled
kind platform
