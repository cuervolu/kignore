scenario characters/bracket-range
kind normative
spec The range notation, e.g. [a-zA-Z], can be used to match one of the characters in a range.
file .gitignore
| file[0-9].txt
| [a-c]x
path file0.txt
path file9.txt
path filea.txt
path file10.txt
path file.txt
path ax
path cx
path dx
path dir/bx

scenario characters/bracket-set-and-negation
kind normative
spec A bracket expression matches one of the listed characters; "!" or "^" right after the opening bracket negates it.
file .gitignore
| a[xyz]
| b[!xyz]
| c[^xyz]
path ax
path az
path aw
path bw
path bx
path cw
path cx
path c/

scenario characters/bracket-does-not-match-slash
kind normative
spec Wildcards in git match with the pathname flag, so a bracket expression never matches a slash.
file .gitignore
| a[!x]b
| c[^x]d
path a-b
path a/b
path c-d
path c/d

scenario characters/bracket-close-first
kind git-quirk
spec Behavior follows fnmatch(3) as used by Git's wildmatch.
note A closing bracket directly after the opening bracket or after the negation is a literal member of the set.
file .gitignore
| a[]]b
| c[!]]d
path a]b
path ab
path a[b
path c-d
path c]d

scenario characters/bracket-reversed-range

scenario characters/bracket-unknown-class
kind git-quirk
spec An unknown POSIX class name is not described by gitignore(5).
note Git treats the whole pattern as non-matching when a class name is unknown.
file .gitignore
| a[[:nosuch:]]
| b[[:digit:]]

path anosuch
path b1

scenario characters/bracket-unterminated

scenario characters/escaped-slash-and-space
kind git-quirk
spec Escapes in front of a separator are not described by gitignore(5).
note Git matches the pattern text verbatim, so an escaped slash behaves like a literal path separator in the pattern.
file .gitignore
| a\/b
| c\ d

path c`sd
path c`sd/x

scenario characters/posix-class-needs-colon-before-first-closing-bracket
kind git-quirk
spec A bracket expression is a POSIX class only when a colon comes right before the first closing bracket after its opening, and otherwise the opening bracket is an ordinary member.
note Found by the differential fuzzer. In `[[:a]:]` the set holds `[`, `:` and `a`, and the characters `:]` follow it.
file .gitignore
| [[:a]:]
| [[:]x
path a:]
path [:]
path a]
path [x
path ax
